FRONTEND PAGES & ROUTING ARCHITECTURE
======================================

Framework: Next.js 14 (App Router)
Language: TypeScript, React 18
Styling: Tailwind CSS, Lucide React Icons
Architecture: Modular App Router with Role-Based Layouts
Total Routes: 24+ Active Pages

===============================================================================
1. STOREFRONT PUBLIC ROUTES (frontend/app/(shop))
===============================================================================

Route: / (Home Page)
File: frontend/app/(shop)/page.tsx
- Hero banner with dynamic gradients and dual CTA ('Shop Now', 'Become a Vendor').
- Real-time statistics counters (500+ products, 100% verified dealers, 8 categories).
- Curated category carousel and grid.
- Dynamic featured products grid with responsive image lazy loading.
- Value proposition badges (Free Shipping, Secure Checkout, 24/7 Support).

Route: /products (Catalog Explorer)
File: frontend/app/(shop)/products/page.tsx
- Faceted multi-criteria filtering sidebar (Search, Category, Min/Max Price, Sort).
- 3-column responsive product card grid.
- Integrated skeleton loading states (ProductCardSkeleton).
- Server-assisted pagination with total items indicator.

Route: /products/[id] (Product Showcase)
File: frontend/app/(shop)/products/[id]/page.tsx
- Breadcrumb navigation path.
- Interactive multi-image gallery with thumbnail selection.
- Vendor trust badge and Shop Name attribution.
- Dynamic quantity selector, real-time stock alert, and 'Add to Cart' animation.

Route: /cart (Shopping Cart)
File: frontend/app/(shop)/cart/page.tsx
- Real-time cart synchronization with backend.
- Inline quantity adjustments (+ / -) and item deletion.
- Financial order summary breakdown (Subtotal, Tax estimate, Total).
- Seamless transition to checkout.

Route: /checkout (Order Placement)
File: frontend/app/(shop)/checkout/page.tsx
- Shipping address capture and pre-fill from user profile.
- Order review accordion with line item breakdown.
- Single-click atomic order placement with inventory lock and cart clearance.

Route: /orders (Customer Order History)
File: frontend/app/(shop)/orders/page.tsx
- Order tracking cards with color-coded status badges (Pending, Confirmed, Processing, Shipped, Delivered, Cancelled).
- Itemized invoice details, pricing, delivery destination, and timestamps.

Route: /account (Customer Profile Management)
File: frontend/app/(shop)/account/page.tsx
- Personal information editor (Full Name, Phone, Shipping Address, AvatarUrl).
- Security center for password updates.

Route: /about (Platform Information)
File: frontend/app/(shop)/about/page.tsx
- Multi-vendor mission statement, core values, platform statistics, and leadership team.

Route: /contact (Help & Support)
File: frontend/app/(shop)/contact/page.tsx
- Interactive contact form, live support channels, and expandable FAQ accordion.
