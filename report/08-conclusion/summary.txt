3. CHALLENGES FACED & ENGINEERING RESOLUTIONS
===============================================================================

1. Legacy Single-Table Identity Collision:
   - Challenge: Combining Admin, Dealer, and Customer in one table led to sparse columns and security risks.
   - Resolution: Migrated to three clean, dedicated tables ('admins', 'dealers', 'customers') with customized schemas and multi-table JWT resolution in AuthService.

2. Multi-Vendor Order Routing & Tenancy:
   - Challenge: In a multi-vendor platform, orders often contain items from multiple independent vendors.
   - Resolution: Linked DealerId directly to OrderItem. Built strict tenancy checks into OrderService and DealerController so dealers can only view, track, and update fulfillment for their respective items.

3. Image Uploading Without Heavy Cloud Storage Dependencies:
   - Challenge: Traditional AWS S3 / Cloudinary configurations require external API keys and billing.
   - Resolution: Engineered 'ImageUploadInput' component that encodes local files directly into Base64 data URLs client-side, while still allowing direct external image URLs.

4. User Experience During Asynchronous Data Loading:
   - Challenge: Cold starts on cloud databases can cause perceived latency.
   - Resolution: Injected global 'LoadingProgress' with multi-stage dynamic labels and smooth cubic-bezier animations, providing immediate, professional visual feedback.
